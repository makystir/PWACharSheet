# Progression Advisor — Implementation Plan

Derived from the APPROVED `design.md` and `requirements.md` in this folder. The feature is **read-only**: a goal-driven recommendation surface on the Advancement page that reuses the existing cost logic and never mutates the character. The work is one cohesive feature and is implemented in dependency order so the codebase stays buildable after each item.

Project commands (from `package.json`, confirmed): typecheck `npx tsc --build --force --noEmit`; build `npm run build`; tests `npx vitest run` (alias of `npm test`); lint `npx eslint .`. Vitest + `fast-check` + `@testing-library/react` are already dev dependencies.

Key grounding confirmed by reading source:
- `planNextCareerLevel` currently resolves the **current** level inline (filters `level1..level5`, finds by `character.careerLevel` title, derives `threshold` from `CAREER_COMPLETION_THRESHOLDS[num] ?? 5`). Its per-requirement loops (characteristics / skill-row minimisation / talent choice) must be extracted so the advisor can cost a *target* level without duplication (design §Code-reuse boundary).
- `AdvancementPage.handleSwitchCareer` computes `switchCost = (readyToProgress ? ADVANCE_LEVEL_FEE.ready : ADVANCE_LEVEL_FEE.notReady) + (sameClass ? 0 : 100)` with `sameClass = newScheme.class === character.class` and `readyToProgress = isReadyToAdvance(character)`. The `+ 100` literal is the different-class surcharge (verified Core p.48 in the design).
- The planner panel uses `Card` + a `headerRow` div wrapping `SectionHeader` (with `collapsible`/`collapsed`/`onToggleCollapse`, far-right chevron) + `HelpPopover concept="career-advancement"`, one `openTooltip` discriminated-union slot, `Tooltip` + `TooltipTriggerCell`, `storageKey` of the `wfrp-collapse-*` form. The advisor mirrors this exactly.
- The planner is currently rendered gated on `scheme && careerLevelNum > 0 && !isMaxLevel`. The advisor must be gated on `scheme && careerLevelNum > 0` only (NOT `!isMaxLevel`) so a max-level character can still target a switch (design §Changed files).
